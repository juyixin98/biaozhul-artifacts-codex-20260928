# Python Restricted Mutation Testing Backend

This project is a local FastAPI + SQLite backend for a restricted set of Python
source mutations. It uses real AST parsing and source rewriting, isolated
project copies, a local pytest command, and durable request evidence.

## Scope

Supported mutation families:

- comparison operators: `==`, `!=`, `<`, `<=`, `>`, `>=`
- binary arithmetic operators: `+`, `-`, `*`, `/`, `//`, `%`
- augmented arithmetic assignments: `+=`, `-=`, `*=`, `/=`, `//=`, `%=`
- conditional inversion: `if condition` is rewritten to the negated condition
- `condition_erase`, an explicit boundary-only operator that removes a condition
  to exercise the invalid-source classification

Mutants are generated from `ast` nodes and unparsed back to source. Source
positions include path, line, column, node type, and original source snippet.

## Fate Semantics

The report keeps distinct categories instead of merging all non-surviving
mutants into one result:

- `syntax_invalid`: the rewritten source fails Python compilation before tests
- `startup_failed`: the test command exits with pytest/collection startup code 2-5
- `killed`: the test command exits with code 1 after a valid mutant is loaded
- `survived`: all tests passed in the mutated copy
- `timeout`: the mutant-specific timeout expired
- `equivalent_undetermined`: conservative static analysis proved equal behavior
- `runner_error`: test command exited with an unclassified non-zero code

Equivalent mutants are marked undetermined. They are not counted as survived,
and the tool does not infer that tests are simply insufficient.

Baseline failure and mutant timeout are separate. The baseline runs first with
`baseline_timeout_seconds`; no mutant is executed unless the baseline passes.
Every baseline and mutant test command runs in a fresh copied project directory.
The original project is never mutated. Before/after SHA-256 Python-file
snapshots and event locations are included in the report.

The `condition_erase` operator deliberately produces a source fragment that
AST unparsing can create but Python compilation rejects. This verifies the
syntax boundary. Normal comparison, arithmetic, and conditional inversion
preserve Python syntax.

## Modules

- `mutation_backend/models.py`: request/response schemas and fate enums
- `mutation_backend/mutator.py`: source discovery, AST mutation, source mapping
- `mutation_backend/equivalence.py`: conservative static equivalence evidence
- `mutation_backend/isolation.py`: project copies and source hashes
- `mutation_backend/runner.py`: argv-only subprocess execution and process-group timeout
- `mutation_backend/engine.py`: baseline, mutation, evidence, and report orchestration
- `mutation_backend/storage.py`: SQLite tables and report persistence
- `mutation_backend/api.py`: FastAPI execution and retrieval endpoints
- `fixtures/sample_algorithm_pkg/`: reusable local algorithm package and tests
- `tests/`: independent assertions for concrete mutant fates and failure classes
- `scripts/`: validation and fixture report runners

## Run

The environment already provides the required packages. No virtual environment
or package installation is necessary in the target machine.

```bash
python3 -m uvicorn mutation_backend.api:app --host 127.0.0.1 --port 8000
```

Create a run:

```bash
curl -s -X POST http://127.0.0.1:8000/mutation-runs \
  -H 'Content-Type: application/json' \
  -d '{
    "request_id": "local-demo",
    "project_path": "/absolute/path/to/fixtures/sample_algorithm_pkg",
    "test_command": ["python3", "-m", "pytest", "-q", "-p", "no:cacheprovider"],
    "source_paths": ["algorithm_pkg/**/*.py"],
    "operators": ["comparison", "arithmetic", "conditional_invert", "condition_erase"],
    "baseline_timeout_seconds": 10,
    "mutant_timeout_seconds": 0.5
  }'
```

Retrieve it:

```bash
curl -s http://127.0.0.1:8000/mutation-runs/local-demo
```

The SQLite path can be changed with `MUTATION_DB_PATH`; temporary workspace roots
can be changed with `MUTATION_WORK_ROOT`. Workspaces default to the system temp
directory and must be outside the analyzed project to prevent recursive copies.

## Validation

Run all required local checks:

```bash
./scripts/verify.sh
```

Generate and persist the bundled fixture report:

```bash
python3 scripts/run_fixture_report.py
```

The bundled fixture has an independently hand-written expected outcome in
`tests/test_engine.py`. It asserts specific counts and IDs for killed,
survived, syntax-invalid, startup-failed, timeout, and equivalent-undetermined
mutants. The expected answers are not generated by the implementation under
test.

## Boundaries And Non-Goals

- Tests are executed sequentially; there is no distributed or parallel worker pool.
- Isolation is filesystem-copy and process-group isolation, not a container or VM.
- Only the listed operators are supported; arbitrary language mutation plugins are not implemented.
- Equivalence detection is intentionally conservative and covers proven numeric constant folding and equivalent constant truth values.
- Network services, cloud credentials, production code, and business datasets are not used.
