# 分片摘要协议

## Summary

矩阵按行主序存储，长度为 `dim*dim`：

```json
{
  "dim": 2,
  "n": 3,
  "weight": 4,
  "origin": [10, 20],
  "means": [0.5, -0.25],
  "means_comp": [0, 0],
  "s1": [2, -1],
  "s1_comp": [0, 0],
  "m2": [1.5, 0.25, 0.25, 2.0],
  "m2_comp": [0, 0, 0, 0]
}
```

字段含义：

- `n`: 正权重观测数量。
- `weight`: `sum(w)`。
- `origin`: 每维本地坐标原点。
- `means`: 相对于 `origin` 的常规 float64 加权均值。
- `means_comp`: 均值的 Neumaier 补偿残差。
- `s1`, `s1_comp`: 相对 `origin` 的补偿加权一阶矩。
- `m2`, `m2_comp`: 相对全局均值的加权偏差乘积和及补偿矩阵。

绝对均值是：

```text
absolute_mean[i] = origin[i] + (s1[i] + s1_comp[i]) / weight
```

总体协方差：

```text
Sigma_pop = (m2 + m2_comp) / weight
```

样本协方差：

```text
Sigma_sample = (m2 + m2_comp) / (weight - 1), weight > 1
```

## 外部提交

服务端接受原始观测：

```json
{
  "shard_id": "worker-a",
  "origin": [1000000000000000, 1000000000000000],
  "observations": [
    {"values": [1000000000000001, 1000000000000002]},
    {"values": [1000000000000000, 1000000000000001], "weight": 2}
  ]
}
```

也接受摘要：

```json
{
  "shard_id": "worker-b",
  "summary": {
    "dim": 2,
    "n": 2,
    "weight": 3,
    "origin": [1000000000000000, 1000000000000000],
    "means": [0.3333333333333333, 0.6666666666666666],
    "s1": [1, 2],
    "m2": [0.6666666666666666, 0, 0, 0.6666666666666666]
  }
}
```

服务端会校验：

- 维度必须和作业一致。
- `n >= 0`、`weight >= 0` 且二者一致。
- 所有权重、观测、原点、矩必须有限。
- `m2` 必须在容差内对称；轻微不对称会被对称化，明显不合法直接拒绝。
- 有效对角方差不能为负，协方差不能违反 Cauchy-Schwarz。
- 同一 `(job_id, shard_id)` 只能合并一次。

## 原点选择

同一作业建议使用共同原点，并且该原点应接近所有分片数据。共同原点路径直接合并相对一阶矩，不执行“加大基数再相减”。不同原点也能合并，但会退化为绝对均值路径，不保证大偏移场景的最高精度。

## 合并公式

对两个摘要 A、B，总权重 `W=WA+WB`：

```text
M = MA + MB + WA*WB/W * (meanA-meanB)(meanA-meanB)^T
S1 = S1A + S1B
```

代码中实际使用补偿数组保存求和残差。测试不要求 float64 逐比特结合律，只要求误差在明确容差内。
